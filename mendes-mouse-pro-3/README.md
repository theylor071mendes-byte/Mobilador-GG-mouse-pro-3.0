# Mendes Mouse Pro 3

Projeto Android original de mapeador. Inclui tela inicial, bolha flutuante, editor simples de tecla para toque em coordenadas e workflow GitHub Actions para compilar APK.

**Limitações:** base inicial; não é uma cópia completa do GG Mouse Pro 3. Não implementa analógico contínuo nem controle relativo de câmera. Usa APIs públicas de Acessibilidade; não injeta código em jogos nem contorna anti-cheat.

Para compilar: envie ao GitHub, abra Actions e execute Build Mendes Mouse Pro 3; baixe o artefato `Mendes-Mouse-Pro-3-debug`.
